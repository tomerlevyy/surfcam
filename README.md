# מצלמת גולשים – אפליקציה לטלפון

אפליקציית רשת: פותחים בדפדפן בטלפון, לוחצים "התחל", והיא מצלמת לבד כשיש רגע טוב.
הזיהוי רץ על הטלפון עצמו (בלי אינטרנט ובלי לשלוח תמונות לשום מקום). אחרי הפתיחה הראשונה היא עובדת גם בלי קליטה.

## התקנה על הטלפון
1. פותחים את הכתובת של האפליקציה ב-Chrome (אנדרואיד) או Safari (אייפון).
2. תפריט הדפדפן ← "הוסף למסך הבית". מקבלים אייקון כמו אפליקציה רגילה.
3. בפתיחה הראשונה מאשרים גישה למצלמה.

## בים
- הטלפון על חצובה יציבה, בגובה, השמש מאחוריך.
- בהגדרות: מגדילים זום עד שהגולש נראה לפחות בגובה אצבע על המסך (עובד בטלפונים שתומכים בזום מהדפדפן, בעיקר אנדרואיד).
- "סף צילום": נמוך = יותר תמונות, גבוה = רק הרגעים החזקים.
- התמונות נשמרות בגלריה שבתוך האפליקציה. "שמור / שתף" שולח אותן לגלריית הטלפון, לוואטסאפ או לדרייב.
- כל צילום נשמר פעמיים: ממוסגר (גולש על קו השליש) ותמונה מלאה.

## מגבלות בגרסה הזו
- האיכות תלויה בזום של הטלפון. גולש רחוק ב-120 מטר ייצא קטן. לתמונות אמיתיות ממרחק צריך מצלמה עם עדשת טלה (השלב הבא).
- זיהוי כ-2–3 פעמים בשנייה. המערכת שומרת את הפריימים האחרונים ובוחרת את החד ביותר סביב רגע השיא.
- עריכת AI כבדה (הגדלה ושחזור) רצה במחשב: `python edit.py` בתיקיית התוכנה הראשית.

## קבצים
index.html, app.js (מצלמה, גלריה), brain.js (מעקב, ציון, מתי לצלם), worker.js (זיהוי), opencv.js + yolox_nano.onnx (מודל הזיהוי), sw.js (עבודה בלי אינטרנט).
